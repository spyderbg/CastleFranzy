A Standard shader good for props and characters

Diffuse map
Normal map
Specular map: Spec map color is used and spec map alpha controls the shininess of the material
You can use these features to simulate different material types within this single shader
For instance you can make cloth with a low and broad specular highlight (dark color, dark alpha), leather with high and narrow spec (bright color, medium grey alpha ), silk with a spec color different from the diffuse (bright color, bright alpha), etc
