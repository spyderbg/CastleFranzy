1.Copy animationselector.ms to your Max "Scripts" directory, typically 3dsmax9\Scripts

2.Run animselector.mcr from the MAXScript/Run Script menu or just drag and drop it into max viewport, then you can add a button in a toolbar by 
	-going in Customize/Customize User Interface
	-select the Toolbars tab
	-choose the Gameloft Category and drag n drop the "Animtaion Selector" in a toolbar
3.Press the button or run the animationselector.ms script to add new note tracks or use existing note tracks to manage animations list
