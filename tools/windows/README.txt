Castle Frenzy - Windows x64

Run bin/FortressDefender.exe. The assets directory beside bin is located
regardless of the current working directory. OpenAL32.dll is built for x64
and included beside the executable; do not replace it with legacy x86 DLLs.

Install the Microsoft Visual C++ 2015-2022 Redistributable (x64) if Windows
reports a missing VCRUNTIME140.dll or MSVCP140.dll.

OpenAL Soft 1.24.3 is licensed under the LGPL; see licenses/OpenAL-Soft.txt.
Source: https://github.com/kcat/openal-soft/tree/1.24.3
Build with CMake and a 64-bit compiler (see the project readme.txt).
